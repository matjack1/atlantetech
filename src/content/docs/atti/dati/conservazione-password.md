## In breve

Le password vanno conservate solo come hash prodotti da funzioni crittografiche adatte (funzioni di derivazione della chiave con salt), mai in chiaro o con algoritmi superati. Concretizza l’art. 32 GDPR per chiunque gestisca un login.
