# Normativa ICT

Mappa della normativa italiana ed europea per SaaS e digitale (Astro + Starlight).

```sh
npm run dev     # http://localhost:4321
npm run build   # sito statico in dist/
```

- Schede: `src/content/docs/atti/{saas,condizionali,digitale}/*.md`
- Schema frontmatter: `src/content.config.ts`
- Come scrivere una scheda: `src/content/docs/metodo/scheda.md`
